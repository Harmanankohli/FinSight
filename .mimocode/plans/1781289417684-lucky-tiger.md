<h3>Merging agents/ into orchestrator/</h3>
<p>The <code>agents/finsight_agent/</code> directory is an alternative ADK web entry point that duplicates callbacks from <code>agent_1_adk/</code>.</p>
<ol>
  <li>Move <code>agents/finsight_agent/agent.py</code> → <code>orchestrator/web/agent.py</code></li>
  <li>Move <code>agents/finsight_agent/__init__.py</code> → <code>orchestrator/web/__init__.py</code></li>
  <li>Move <code>agents/finsight_agent/.adk/</code> → <code>orchestrator/web/.adk/</code></li>
  <li>Move <code>agents/services.py</code> → <code>orchestrator/web/services.py</code> (or into <code>shared/</code>)</li>
  <li>Delete <code>agents/</code> directory entirely</li>
</ol>

<h2 id="part2">Part 2: Code Issues</h2>

<h3 id="p0"><span class="severity p0">P0</span> Critical — Fix Immediately</h3>

<div class="issue p0">
  <h3>1. DCF Terminal Value Formula Bug</h3>
  <p class="file">agent_3_langgraph/nodes/dcf.py:130</p>
  <p><strong>Issue:</strong> Terminal value uses <code>growth_rate ** 5</code> for compounding, but the FCF projection loop (lines 121–128) already tapers growth toward <code>terminal_growth</code>. This double-counts high growth, inflating intrinsic value for growth stocks.</p>
  <p class="fix"><strong>Fix:</strong> Use the year-5 projected FCF from the loop: <code>terminal_value = (projected_fcf_year5 * (1 + terminal_growth)) / (wacc - terminal_growth)</code></p>
</div>

<div class="issue p0">
  <h3>2. Access Token Cookie Without HttpOnly — XSS Vulnerability</h3>
  <p class="file">web/nextjs-app/lib/auth.ts:18–19</p>
  <p><strong>Issue:</strong> <code>setTokenCookie</code> sets <code>document.cookie</code> without <code>HttpOnly</code>. The access token is readable by JavaScript, vulnerable to XSS exfiltration.</p>
  <p class="fix"><strong>Fix:</strong> Remove client-side access token cookie. Use only in-memory React state. If cookie needed for SSR, set <code>HttpOnly</code> and <code>Secure</code> flags server-side.</p>
</div>

<div class="issue p0">
  <h3>3. Fallback Password Hasher Stores Plaintext</h3>
  <p class="file">shared/memory/user_store.py:23–33</p>
  <p><strong>Issue:</strong> When <code>argon2</code> is not installed, <code>_FallbackHasher</code> stores <code>plain:{password}</code>. Dangerous if deployed without argon2.</p>
  <p class="fix"><strong>Fix:</strong> Make argon2 a hard dependency (add to pyproject.toml). Remove the fallback hasher entirely.</p>
</div>

<div class="issue p0">
  <h3>4. mypy Strict Mode Disabled for All Modules</h3>
  <p class="file">pyproject.toml:244–254</p>
  <p><strong>Issue:</strong> <code>strict = true</code> is set but <code>ignore_errors = true</code> is applied to ALL production modules. mypy is effectively off.</p>
  <p class="fix"><strong>Fix:</strong> Remove <code>ignore_errors</code> overrides. Fix type errors incrementally, starting with <code>shared/</code> then agents one at a time.</p>
</div>

<h3 id="p1"><span class="severity p1">P1</span> High — Fix Soon</h3>

<div class="issue p1">
  <h3>5. CrewAI asyncio.run() Inside Async Context</h3>
  <p class="file">agent_4_crewai/mcp_tools.py:55–61</p>
  <p><strong>Issue:</strong> <code>asyncio.run(self._mcp.call_by_name(...))</code> creates a new event loop inside an already-running async context. Raises <code>RuntimeError</code> under certain conditions.</p>
  <p class="fix"><strong>Fix:</strong> Use <code>nest_asyncio.apply()</code> as workaround, or restructure CrewAI tools to receive a synchronous MCP client.</p>
</div>

<div class="issue p1">
  <h3>6. CrewAI crew.kickoff() Blocks Event Loop</h3>
  <p class="file">agent_4_crewai/crew.py:114–115</p>
  <p><strong>Issue:</strong> Synchronous blocking <code>kickoff()</code> called inside <code>async def analyze()</code>, starving other coroutines while running.</p>
  <p class="fix"><strong>Fix:</strong> Wrap in <code>loop.run_in_executor(None, crew.kickoff)</code> to avoid blocking.</p>
</div>

<div class="issue p1">
  <h3>7. HuggingFace Download Blocks Event Loop</h3>
  <p class="file">agent_2_llamaindex/index_manager.py:127–141</p>
  <p><strong>Issue:</strong> ~130MB synchronous download during <code>__init__</code> at server startup. Stalls for minutes.</p>
  <p class="fix"><strong>Fix:</strong> Move into <code>run_in_executor</code> or lazy-load on first query.</p>
</div>

<div class="issue p1">
  <h3>8. Reranker Blocks Event Loop</h3>
  <p class="file">agent_2_llamaindex/hybrid_search.py:100–108</p>
  <p><strong>Issue:</strong> Synchronous CPU-bound <code>CrossEncoder.predict</code> (neural inference) called inside <code>async def</code>. Blocks the event loop for hundreds of milliseconds.</p>
  <p class="fix"><strong>Fix:</strong> Wrap in <code>await loop.run_in_executor(None, self.reranker.predict, pairs)</code>.</p>
</div>

<div class="issue p1">
  <h3>9. 63 Bare except Exception: Blocks Swallowing Errors</h3>
  <p class="file">Throughout codebase — notable: shared/memory/store.py, agent_1_adk/agent_executor.py, agents/finsight_agent/agent.py</p>
  <p><strong>Issue:</strong> Broad exception catches without <code>exc_info=True</code> or specific types lose failure context. Migration errors logged at <code>debug</code> level only.</p>
  <p class="fix"><strong>Fix:</strong> Add <code>exc_info=True</code> to all catches. Narrow exception types where possible. Use <code>logger.exception()</code> instead of <code>logger.debug()</code> for failures that matter.</p>
</div>

<div class="issue p1">
  <h3>10. Hardcoded api_key="lm-studio" Bypassing Settings</h3>
  <p class="file">shared/runtime_eval.py:181</p>
  <p><strong>Issue:</strong> Hardcoded API key instead of using <code>LLM_API_KEY</code> from settings.</p>
  <p class="fix"><strong>Fix:</strong> Use <code>LLM_API_KEY</code> constant from settings.</p>
</div>

<div class="issue p1">
  <h3>11. Session-ID Fallback Mixes Concurrent Responses</h3>
  <p class="file">agent_1_adk/agent.py:100–108</p>
  <p><strong>Issue:</strong> When exact session_id match fails, falls back to "most recent entry." Under concurrent load, can serve wrong user's data.</p>
  <p class="fix"><strong>Fix:</strong> Key entries by <code>(session_id, request_id)</code>. Require exact match. Log error on fallback.</p>
</div>

<div class="issue p1">
  <h3>12. Redis: No Auth, No Health Check, No Persistence</h3>
  <p class="file">docker-compose.yml:110–113</p>
  <p><strong>Issue:</strong> Redis exposed on port 6379 with no password, no health check, no volume.</p>
  <p class="fix"><strong>Fix:</strong> Add <code>requirepass</code>, <code>healthcheck</code>, <code>volumes</code>, and <code>depends_on</code> to services that need Redis.</p>
</div>

<div class="issue p1">
  <h3>13. chromadb Missing from Main Dependencies</h3>
  <p class="file">pyproject.toml:7–69</p>
  <p><strong>Issue:</strong> Only in optional extras. <code>pip install .</code> without extras causes runtime import errors.</p>
  <p class="fix"><strong>Fix:</strong> Add to main dependencies or document extras as mandatory.</p>
</div>

<div class="issue p1">
  <h3>14. Access Token Cookie Missing Secure Flag</h3>
  <p class="file">web/nextjs-app/lib/auth.ts:19</p>
  <p><strong>Issue:</strong> Cookie sent over HTTP, exposing token to network interception.</p>
  <p class="fix"><strong>Fix:</strong> Add <code>; Secure</code> flag in production.</p>
</div>

<h3 id="p2"><span class="severity p2">P2</span> Medium — Address When Able</h3>

<div class="issue p2">
  <h3>15. Memory Leaks from In-Memory Dicts</h3>
  <p class="file">agent_1_adk/agent.py:21, agent_1_adk/auth_routes.py:40, mcp_servers/tools/edgar.py:55–71</p>
  <p><strong>Issue:</strong> <code>_agent_responses</code> accumulates entries (only cleaned on pop), <code>_login_buckets</code> never pruned, <code>_edgar</code> httpx client never closed.</p>
  <p class="fix"><strong>Fix:</strong> Add periodic background cleanup tasks. Use LRU caches with max size. Add shutdown hooks.</p>
</div>

<div class="issue p2">
  <h3>16. Race Conditions</h3>
  <p class="file">agent_1_adk/agent.py:70–76, agent_2_llamaindex/index_manager.py:143–158, agent_3_langgraph/nodes/state.py:9–15</p>
  <p><strong>Issue:</strong> Concurrent session writes overwrite each other, index creation not thread-safe, <code>_merge_dict</code> shallow merge loses data.</p>
  <p class="fix"><strong>Fix:</strong> Per-session locks or <code>(session_id, request_id)</code> keying. <code>asyncio.Lock</code> per collection. Deep merge.</p>
</div>

<div class="issue p2">
  <h3>17. Code Duplication Across 3 Orchestrator Paths</h3>

<div class="issue p2">
