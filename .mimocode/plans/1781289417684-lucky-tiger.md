<h3>Merging agents/ into orchestrator/</h3>
<p><code>agents/finsight_agent/</code> is NOT a separate agent. It's a callback extension module that adds <code>before_agent_callback</code> and <code>after_agent_callback</code> to the orchestrator's <code>root_agent</code> for memory persistence and eval — used only in <code>adk web</code> mode.</p>
<ol>
  <li>Move <code>agents/finsight_agent/agent.py</code> → <code>orchestrator/web/agent.py</code></li>
  <li>Move <code>agents/finsight_agent/__init__.py</code> → <code>orchestrator/web/__init__.py</code></li>
  <li>Move <code>agents/finsight_agent/.adk/</code> → <code>orchestrator/web/.adk/</code></li>
  <li>Move <code>agents/services.py</code> → <code>orchestrator/web/services.py</code> (or into <code>shared/</code>)</li>
  <li>Delete <code>agents/</code> directory entirely</li>
</ol>

<h3 id="p0"><span class="severity p0">P0</span> Critical — Fix Immediately</h3>

<div class="issue p0">
  <h3>1. DCF Terminal Value Formula Bug</h3>
  <p class="file">agent_3_langgraph/nodes/dcf.py:130</p>
  <p><strong>Issue:</strong> Terminal value uses <code>growth_rate ** 5</code> for compounding, but the FCF projection loop (lines 121–128) already tapers growth toward <code>terminal_growth</code>. Double-counts high growth, inflating intrinsic value for growth stocks.</p>
  <p class="fix"><strong>Fix:</strong> Use year-5 projected FCF: <code>terminal_value = (projected_fcf_year5 * (1 + terminal_growth)) / (wacc - terminal_growth)</code></p>
</div>

<div class="issue p0">
  <h3>2. Access Token Cookie Without HttpOnly — XSS Vulnerability</h3>
  <p class="file">web/nextjs-app/lib/auth.ts:18–19</p>
  <p><strong>Issue:</strong> <code>setTokenCookie</code> sets <code>document.cookie</code> without <code>HttpOnly</code>. Access token readable by JavaScript, vulnerable to XSS exfiltration.</p>
  <p class="fix"><strong>Fix:</strong> Remove client-side cookie. Use only in-memory React state. If cookie needed for SSR, set <code>HttpOnly</code> and <code>Secure</code> flags server-side.</p>
</div>

<div class="issue p0">
  <h3>3. Fallback Password Hasher Stores Plaintext</h3>
  <p class="file">shared/memory/user_store.py:23–33</p>
  <p><strong>Issue:</strong> <code>_FallbackHasher</code> stores <code>plain:{password}</code> when argon2 not installed. Dangerous if deployed without argon2.</p>
  <p class="fix"><strong>Fix:</strong> Make argon2 a hard dependency. Remove the fallback hasher entirely.</p>
</div>

<div class="issue p0">
  <h3>4. mypy Strict Mode Disabled for All Modules</h3>
  <p class="file">pyproject.toml:244–254</p>
  <p><strong>Issue:</strong> <code>strict = true</code> set but <code>ignore_errors = true</code> applied to ALL production modules. mypy is effectively off.</p>
  <p class="fix"><strong>Fix:</strong> Remove <code>ignore_errors</code> overrides. Fix type errors incrementally.</p>
</div>

<!-- P1 -->
<h3 id="p1"><span class="severity p1">P1</span> High — Fix Soon</h3>

<div class="issue p1">
  <h3>5. Portfolio Store Uses session_id as user_id <span class="new-badge">NEW</span></h3>
  <p class="file">shared/memory/portfolio_store.py:57–58, 75–76, 83–85</p>
  <p><strong>Issue:</strong> <code>upsert_from_context</code> queries/inserts <code>user_profiles</code> using <code>ctx.session_id</code> as <code>user_id</code>. Each session creates a separate portfolio profile — a user analyzing the same stock across two sessions gets disconnected portfolios.</p>
  <p class="fix"><strong>Fix:</strong> Use <code>ctx.user_id</code> (authenticated user ID) instead of <code>ctx.session_id</code>.</p>
</div>

<div class="issue p1">
  <h3>6. Sessions List Allows user_id from Query Params (Auth Bypass) <span class="new-badge">NEW</span></h3>
  <p class="file">agent_1_adk/api_routes.py:131</p>
  <p><strong>Issue:</strong> <code>user_id = _user_id(request) or request.query_params.get("user_id")</code> — when auth is enabled and <code>_user_id</code> returns <code>None</code>, the fallback reads <code>user_id</code> from query params. An unauthenticated user could pass <code>?user_id=admin</code> and see that user's sessions.</p>
  <p class="fix"><strong>Fix:</strong> Only fall back to query params when auth is disabled. When auth is enabled, reject requests where <code>_user_id</code> returns <code>None</code>.</p>
</div>

<div class="issue p1">
  <h3>7. Report Authorization Bypass for user_id=None <span class="new-badge">NEW</span></h3>
  <p class="file">agent_1_adk/api_routes.py:233–254</p>
  <p><strong>Issue:</strong> <code>report_by_id()</code> SQL: <code>WHERE id = ? AND (user_id = ? OR ? IS NULL)</code>. When <code>_user_id(request)</code> returns <code>None</code>, the <code>IS NULL</code> clause is always True — any user can access any report.</p>
  <p class="fix"><strong>Fix:</strong> When auth is enabled, reject requests where <code>_user_id</code> returns <code>None</code>.</p>
</div>

<div class="issue p1">
  <h3>8. CrewAI asyncio.run() Inside Async Context</h3>
  <p class="file">agent_4_crewai/mcp_tools.py:55–61</p>
  <p><strong>Issue:</strong> <code>asyncio.run(self._mcp.call_by_name(...))</code> creates new event loop inside running async context. Raises <code>RuntimeError</code>.</p>
  <p class="fix"><strong>Fix:</strong> Use <code>nest_asyncio</code> or restructure to synchronous MCP client.</p>
</div>

<div class="issue p1">
  <h3>9. CrewAI crew.kickoff() Blocks Event Loop</h3>
  <p class="file">agent_4_crewai/crew.py:114–115</p>
  <p><strong>Issue:</strong> Sync blocking <code>kickoff()</code> in <code>async def analyze()</code> starves other coroutines.</p>
  <p class="fix"><strong>Fix:</strong> Wrap in <code>loop.run_in_executor(None, crew.kickoff)</code>.</p>
</div>

<div class="issue p1">
  <h3>10. HuggingFace Download Blocks Event Loop</h3>
  <p class="file">agent_2_llamaindex/index_manager.py:127–141</p>

  <p class="fix"><strong>Fix:</strong> Move to <code>run_in_executor</code> or lazy-load on first query.</p>
</div>

<div class="issue p1">
  <h3>11. Reranker Blocks Event Loop</h3>
