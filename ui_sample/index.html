An analyst team that answers “should I invest?”

FinSight coordinates four specialized agents — each built on a different framework — into a single, citation-backed investment brief. The orchestrator delegates over the Agent-to-Agent protocol, every agent pulls live data through one MCP server, and the whole run streams to a CopilotKit v2 chat surface over AG-UI.

What makes it sturdy

The infrastructure beneath the brief.

01

Multi-tier caching

TTL tool cache (1 min prices → 7 day shocks), LangChain SQLite LLM cache, and ChromaDB semantic cache for repeated queries.

02

Input & output guardrails

Off-topic filter, pre-flight ticker validation, empty-response guard, and BUY/HOLD/SELL signal enforcement with auto-retry.

03

Persistent memory

SQLite ticker briefs, portfolio holdings, and recommendation tracking with live price snapshots — same-day cache in ~200ms.

04

Distributed tracing

Langfuse joins all four agent processes into one trace tree via text-based A2A context propagation, with noise filtering.

05

Runtime RAGAS eval

Per-query Faithfulness, FactualCorrectness and relevancy scored in the background, streamed per-metric to Langfuse.

06

Local-first inference

Every agent runs on LM Studio (OpenAI-compatible) with local embeddings and reranker — no cloud dependency required.
