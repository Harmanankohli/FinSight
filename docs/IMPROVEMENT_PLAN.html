Phase 1 — Production Hardening

These changes prevent accidental production exposure and enable self-healing. Estimated effort: 1–2 hours total.

1.1 Gate debug=True on Environment

HIGH TODO

Problem: All four agent servers and the MCP server run with debug=True, enabling auto-reload and detailed error pages. This exposes internal state in production.

Files:

  • agent_1_adk/main.py
  • agent_2_llamaindex/server.py
  • agent_3_langgraph/server.py
  • agent_4_crewai/server.py
  • mcp_servers/finsight_server.py

Change: Replace hardcoded debug=True with debug=(ENV != "production"). Add ENV=development as default in shared/config.py.

Verify: Set ENV=production and confirm no auto-reload; confirm /health still returns 200.

1.2 Add Circuit Breaker Reset Timer

HIGH TODO

Problem: The eval circuit breaker in shared/runtime_eval.py opens after 5 consecutive RAGAS failures and never resets. A transient LLM outage permanently disables evaluation.

File: shared/runtime_eval.py

Change: Add a _circuit_opened_at timestamp. In _gate_ok(), check if time.time() - _circuit_opened_at > CIRCUIT_RESET_SECONDS (default 300). If so, transition to half-open: allow 1 eval attempt. If it passes, close the circuit; if it fails, reset the timer.

Verify: Unit test: open circuit, wait > reset window, confirm one eval attempt is allowed.

1.3 Fix MCP Client Singleton at Exit

HIGH TODO

Problem: get_shared_mcp() registers an atexit handler that creates a new event loop via asyncio.new_event_loop() to close the client. This can fail if the default loop is already running at exit time on some platforms.

File: shared/mcp_client.py

Change: Use weakref.ref for the singleton and register a synchronous close() that sets a flag. The actual async cleanup happens in the running loop via a __del__ or explicit aclose() call from server shutdown hooks.

Verify: Run server startup/shutdown cycle 10x; confirm no RuntimeError or event loop warnings.

1.4 Remove Unused psycopg2-binary Dependency

MED TODO

Problem: pyproject.toml includes psycopg2-binary but no Postgres service exists in docker-compose.yml and no code imports it. Dead dependency increases image size.

File: pyproject.toml

Change: Remove psycopg2-binary from dependencies. If Postgres is planned, add it as an optional extra instead.

Verify: uv sync succeeds; grep -r psycopg2 returns no hits.

Phase 2 — Testing Gaps

Critical path components lack test coverage. Estimated effort: 3–4 hours.

2.1 Add Orchestrator Executor Tests

HIGH TODO

Problem: FinSightAgentExecutor is the most critical component (routes all user queries) but has zero unit tests.

File: tests/unit/test_orchestrator_executor.py (new)

Test cases:

  • Off-topic query rejection (regex guardrail)
  • Invalid ticker rejection (pre-flight MCP validation)
  • Memory cache hit short-circuits LLM
  • Memory context injection with [TODAY] vs [STALE] tag
  • Per-agent timeout returns clean error JSON
  • Output guardrail: response < 50 chars triggers TASK_STATE_FAILED
  • Output guardrail: missing BUY/HOLD/SELL emits Langfuse warning

Verify: pytest tests/unit/test_orchestrator_executor.py -v passes.

2.2 Add AG-UI Bridge Tests

HIGH TODO

Test cases:

  • _build_memory_context() returns correct prefix with ticker extraction
  • _get_today_cached_text() returns cached text when brief exists
  • _auto_save_brief() persists to SQLite with correct fields
  • SSE event format matches CopilotKit expected schema

Verify: pytest tests/unit/test_agui_bridge.py -v passes.

2.3 Add Report Generator Unit Tests

File: tests/unit/test_report_generator.py (new)

Test cases:

  • DeckData extraction from orchestrator response text

Phase 3 — Code Quality

Reduce duplication and improve maintainability. Estimated effort: 2–3 hours.

3.1 Extract Duplicated Agent Utilities

MED TODO

Problem: _build_memory_context(), _get_today_cached_text(), _auto_save_brief(), and _NON_INVESTMENT_RE are duplicated across agent_1_adk/agent_executor.py and agent_1_adk/agui_bridge.py.

Files:

  • Create: shared/agent_utils.py
  • Modify: agent_1_adk/agent_executor.py
  • Modify: agent_1_adk/agui_bridge.py

Change: Move the four shared functions/regexes to shared/agent_utils.py. Import from both files. Keep function signatures identical.

Verify: Existing tests pass; grep -c "_build_memory_context" agent_1_adk/ shows 1 definition, 2 imports.

3.2 Split report_generator.py

MED TODO

Problem: shared/report_generator.py is ~1400 lines mixing data extraction (DeckData) with slide rendering. Hard to navigate and test in isolation.

Files:

  • Create: shared/deck_data.py (data extraction)
  • Modify: shared/report_generator.py (slide rendering only, import from deck_data)

Change: Extract DeckData dataclass and its from_response() factory into shared/deck_data.py. Keep all python-pptx slide logic in report_generator.py.

Verify: pytest tests/unit/test_report_generator.py -v passes (after 2.3 is done).

3.3 Add shared/__init__.py

LOW TODO

Problem: The shared package has no __init__.py, relying on implicit namespace packages. IDE autocompletion and import checking are degraded.

File: shared/__init__.py (new)

Change: Create with public exports: from shared.config import ..., from shared.models import ..., etc. Keep it minimal — just re-exports.

Verify: python -c "import shared; print(dir(shared))" shows exported names.

3.4 Fix Module-Level Mutable State in eval_gate.py

MED TODO

Problem: shared/eval_gate.py uses module-level _deferred list and _auto_release_task. This is not safe for multiple event loops (e.g., testing with pytest-asyncio).

File: shared/eval_gate.py

Change: Wrap state in an EvalGate class with defer() and release() methods. Provide a module-level _default_gate = EvalGate() for backward compatibility.

Verify: Existing tests pass; new test confirms two independent EvalGate instances don't share state.

Phase 4 — Scaling & Persistence

Enable horizontal scaling beyond a single process. Estimated effort: 4–6 hours.

4.1 Abstract Persistent Store Interface

MED TODO

Problem: All persistent state (tasks, memories, recommendations) lives in SQLite via a single connection. Cannot scale to multiple orchestrator instances.

Files:

  • Create: shared/store_interface.py (abstract base)
  • Modify: shared/a2a_store.py (implement interface)
  • Modify: shared/memory/store.py (implement interface)

Change: Define TaskStore and MemoryStore abstract base classes. Refactor existing SQLite implementations to conform. Add a Postgres implementation as an optional extra behind extras = ["postgres"] in pyproject.toml.

Verify: All existing tests pass against SQLite backend; new tests validate the interface contract.

4.2 Add Postgres Service to Docker Compose

MED TODO

Problem: pyproject.toml was originally designed for Postgres (includes psycopg2-binary) but the service was never added to docker-compose.yml.

File: docker-compose.yml

Change: Add a postgres service with POSTGRES_DB=finsight, POSTGRES_USER, POSTGRES_PASSWORD from env. Add DATABASE_URL to agent environment variables. Conditionally use Postgres when DATABASE_URL is set, fall back to SQLite otherwise.

Verify: docker compose up postgres starts; agents connect when DATABASE_URL is set.
