1. Current Logging Infrastructure

What exists

  • shared/logging_config.py - JSON formatter, SanitizeFilter, @logged decorator, setup_file_logging()
  • ~30 modules have logger = logging.getLogger(__name__)
  • File output: logs/<service>.log (JSON lines, 10MB rotating, 5 backups)
  • Console handler: plaintext to stderr
  • Trace context: current_trace_id / current_session_id ContextVars auto-injected

What is missing

  • 13 files have no import logging at all
  • ~15 except blocks silently swallow errors (pass or no log call)
  • Cache hit/miss, DB operations, and state transitions are mostly unlogged
  • No @logged decorator usage outside of logging_config.py itself

6. Implementation Examples

Example: Adding logging to a file with zero infrastructure

import logging

logger = logging.getLogger(__name__)

# Before:
async def store_brief(self, brief, user_id, session_id):
    record_id = str(uuid.uuid4())
    async with write_lock():
        ...
    return record_id

# After:
async def store_brief(self, brief, user_id, session_id):
    record_id = str(uuid.uuid4())
    async with write_lock():
        ...
    logger.info("Stored brief %s for %s (rec=%s, conf=%.2f)",
        record_id, brief.ticker, brief.final_recommendation,
        brief.confidence_score)
    return record_id

Example: Fixing a silent except block

# Before:
except Exception:
    pass

# After:
except Exception as exc:
    logger.warning("Operation failed: %s", exc)

Example: Using the @logged decorator

from shared.logging_config import logged

# Apply to hot-path async functions (MCP tools, agent stream)
# Logs: "Enter fn" / "Exit fn (123ms)" / "Fail fn (123ms): error"

@logged(level=logging.INFO)
async def stream(self, query, context_id, task_id):
    ...
