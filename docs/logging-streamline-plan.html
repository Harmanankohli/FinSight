Logging Streamline Plan

Implementation plan for a coding agent to bring logging coverage to 100% across FinSight. Ordered by priority — each phase is independently shippable.

Current State

The codebase has a mature centralized logging infrastructure in shared/logging_config.py. It provides JSON-lines file output (ingestible by Loki/CloudWatch/Datadog), plaintext console output, secret sanitization, @logged/@logged_sync/@logged_class decorators, and per-service log level control via environment variables. Langfuse + OpenTelemetry tracing is wired up in shared/observability.py. Trace context propagates across A2A boundaries via shared/trace_context.py.

The problem is not infrastructure — it's coverage. 12 files have no logging at all. 11 except blocks silently swallow errors. Several hot paths lack operational visibility. The logs/ directory has 45+ files with inconsistent naming.

P1 Fix Silent Exception Blocks

Risk: These blocks hide failures that are invisible in production. A migration failure, a cache corruption, or a sandbox resource limit error will produce zero log output.

Rule: Every except block must either log or have a comment explaining why silence is intentional. Use logger.debug for expected/benign cases, logger.warning for unexpected-but-recoverable cases.

P4 Suppress Third-Party Log Noise

Problem: Third-party libraries (httpx, urllib3, asyncio, aiosqlite, langfuse, chromadb, sentence_transformers) log at their default levels. At LOG_LEVEL=DEBUG, they flood the output with internal HTTP request details, connection pool events, and model loading messages that bury FinSight's own log lines.

Where to add: In shared/logging_config.py, at the end of setup_file_logging(), after the handlers are attached.

Code to add 
# Suppress noisy third-party loggers to WARNING unless explicitly overridden.
_NOISY_LOGGERS = [
    "httpx", "httpcore", "urllib3", "asyncio",
    "aiosqlite", "chromadb", "sentence_transformers",
    "langfuse", "opentelemetry", "grpc",
]
for name in _NOISY_LOGGERS:
    lib_logger = logging.getLogger(name)
    env_override = os.environ.get(f"LOG_LEVEL_{name.upper().replace('.', '_')}")
    if env_override:
        lib_logger.setLevel(getattr(logging, env_override.upper(), logging.WARNING))
    elif lib_logger.level == logging.NOTSET or lib_logger.level < logging.WARNING:
        lib_logger.setLevel(logging.WARNING)

This preserves the ability to debug specific libraries with LOG_LEVEL_HTTPX=DEBUG while keeping the default clean.

  2. Logger coverage: grep -rL "logging.getLogger" --include="*.py" shared/ agents/ — should return only __init__.py files and shared/peer_sets.py (pure data).

  4. Test run: Start the orchestrator with LOG_LEVEL=DEBUG, run a query for one ticker, and verify:
    • All 5 canonical log files are written to
    • JSON format is valid (each line parseable with json.loads())
    • No secrets appear in log output
    • trace_id appears in log lines after the first A2A call
    • Third-party logger noise is suppressed at DEBUG level
  5. Import check: python -c "from shared.logging_config import setup_file_logging, logged, logged_sync, logged_class" succeeds without error.

Implementation Order for a Coding Agent

  1. P1 (30 min) — Fix silent except blocks. This is the highest-value change — it makes invisible failures visible. Ship as its own commit: "fix(logging): add log output to 11 silent except blocks"
  2. P2 (15 min) — Add logger boilerplate to remaining files. Commit: "chore(logging): add logger to 7 files missing logging imports" (P1 already covered 5 of the 12)
  3. P3 (45 min) — Add operational log statements. This is the bulk of the work. Commit: "feat(logging): add operational log statements to memory, sandbox, report, and cache modules"
  4. P4 (10 min) — Suppress third-party noise. Commit: "chore(logging): suppress noisy third-party loggers to WARNING"
  5. P5 (20 min) — Expand @logged decorator. Commit: "feat(logging): apply @logged decorator to executor and hot-path functions"
  6. P6 (5 min) — Clean up log files. Commit: "chore: clean stale log files, document canonical names"
  7. P7 (5 min) — Fix minor inconsistencies. Commit: "fix(logging): fix hardcoded logger name, stale docstring import, silent trace parse"

Total estimated time: ~2 hours. Each phase is independently testable and shippable.
