Demo: End-to-End Investment Query

This walkthrough shows the full pipeline for the query “Should I invest in NVDA?”

Architecture Flow

User Query → ADK Web (8001) → ADK LlmAgent
  → Memory context injection (latest NVDA brief + portfolio)
  → LLM calls agents via single send_message tool (parallel with qwen):
    → send_message("Financial RAG Agent", ...) → RAG Agent (8002) → MCP → ChromaDB
    → send_message("Quant Analysis Agent", ...) → Quant Agent (8003) → MCP → LangGraph
    → send_message("Sentiment Intelligence Agent", ...) → Sentiment Agent (8004) → MCP → CrewAI
  → LLM synthesizes all results → BUY/HOLD/SELL recommendation
  → Auto-save: brief, portfolio, performance record persisted to SQLite

Memory Layer

After each query, the system automatically persists:

  • Ticker brief: Latest recommendation (BUY/HOLD/SELL + confidence + rationale)
  • Portfolio holdings: Extracted from user query context, merged over time
  • Performance record: Recommendation timestamped for future accuracy tracking
  • Session events: Full conversation stored for cross-session search via load_memory

On subsequent queries, memory context is injected, enabling the orchestrator to answer questions like “Has the outlook for NVDA changed since last time?”

Step 1: Start Services

run_adk_web.bat

Starts in order: MCP Server (8010) → RAG (8002) → Quant (8003) → Sentiment (8004) → ADK Web UI (8001)

Step 2: Send Query

Open http://127.0.0.1:8001 and type: “Should I invest in NVDA?” or just “NVDA”.

Step 3: What Happens

StepComponentAction
1ADK LlmAgentReceives query, decides which tools to call
2Agent Tool fnCalls _client.send_message(agent_name, task)
3SubAgentClientLazily creates A2A client, sends SendMessageRequest
4Sub-agent serverGenericAgentExecutor runs the agent's stream()
5Sub-agent logicEach agent processes with its own tools (MCP, etc.)
6ResponseAgent yields {response_type, content, is_task_complete}
7Orchestrator_extract_text converts response to string
8LLM synthesisAll agent results returned to LLM → final recommendation

Direct A2A Testing

Test individual agents without the ADK Web UI:

Test RAG Agent

curl -X POST http://localhost:8002/a2a \
  -H "Content-Type: application/json" \
  -H "A2A-Version: 1.0" \
  -d '{"jsonrpc":"2.0","method":"SendMessage","id":"1","params":{"message":{"messageId":"1","role":"ROLE_USER","parts":[{"text":"Research NVDA"}]},"metadata":{"ticker":"NVDA"}}}'
