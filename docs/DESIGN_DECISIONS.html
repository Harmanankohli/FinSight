Key Lessons

  1. messageId is required on every A2A Message
  2. agentInterface must match: ClientFactory requires supported_interfaces with protocol_binding="JSONRPC"
  3. Timeout propagation: Both ClientConfig + httpx.AsyncClient AND ClientCallContext must be configured
  4. Response format: Sub-agents return data (structured) not text — extract via get_data_parts()
  5. Streaming events: Intermediate SUBMITTED/WORKING status updates must be skipped
  6. Data > text: Sub-agents emit Part(data=Value(struct_value=s)) for structured responses

Problems Encountered

1. asyncio.run() and Running Event Loops

Module-level asyncio.run() fails when ADK Web UI imports the module. Check for an existing loop first: use loop.create_task() if running, asyncio.run() otherwise.

2. httpx Event Loop Conflicts from Threaded Init

httpx.AsyncClient is never created in a thread or at module level.

3. httpx.Timeout Constructor Ambiguity

httpx.Timeout(read=300.0, connect=10.0) fails. Use httpx.Timeout(300.0).

4. Sub-agent Responses in data Format Not Extracted

get_stream_response_text() only returns text. Sub-agents return structured data parts. Check get_data_parts(artifact.parts) first.

5. Streaming Event Handling — Early Return on WORKING

Route events by type: skip SUBMITTED/WORKING, only process artifact_update and terminal events.

6. Non-terminal Task Events Returned as Result

Check task.status.state not in _TERMINAL_STATES before processing task events.

7. Local LLMs Don't Support Parallel Function Calling

Single send_message tool. Qwen model supports parallel calls; others are sequential.

8. MCP Resource URI Type Mismatch

Convert AnyUrl to string with str(uri).

9. ClientConfig Has No timeout Parameter

Pass pre-configured httpx.AsyncClient(timeout=httpx.Timeout(300)) via ClientConfig(httpx_client=http).

10. LLM Tool Name Hallucination

Single send_message tool eliminates wrong tool names.

11. Agent Name Validation Error

LlmAgent(name="FinSight Orchestrator") — spaces not allowed. Use name="orchestrator".

12. Slow-Starting Sub-agents Not Discovered

discover() retries each URL 3 times with 5-second delay.

13. MCP Registry Discovery Not Ported

Pending future work.

14. Windows ConnectionResetError Noise

asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy()) on Windows.

15. AgentCard Protobuf — No url Field

Set supported_interfaces=[AgentInterface(protocol_binding="JSONRPC", url=...)] instead.

Timeout Strategy

Pass a pre-configured httpx.AsyncClient(timeout=httpx.Timeout(300)) via ClientConfig(httpx_client=http).

MCP Server Design

Docker-compose Alignment Fix

Replaced 4 broken MCP services with single finsight-mcp service.

Lazy Agent Registry

Model loading deferred to first tool call via _ensure_registry() with asyncio.Lock double-checked locking.

Windows Compatibility

import resource guarded with if sys.platform != "win32".

Thread-Safe SSE App Singleton

get_app() with threading.Lock double-checked singleton pattern.

SEC EDGAR Caching

_EdgarClient._get_ticker_map() with asyncio.Lock lazy loading. CIK results cached in _cik_cache.

Sandbox Hardening

Expanded _RESTRICTED_IMPORTS and _RESTRICTED_ATTRS blocklists. Subprocess runs with -I and -S flags.

RAG Agent Auto-ingest

Fetches SEC filings via MCP on first query. Fixed with proper empty-check and try/except json.JSONDecodeError.

RAG Content Ingestion Fix

Added get_filing_content() MCP tool. RAG agent now stores actual filing text instead of just metadata.

Quant DCF Null Fix

Changed to read free cash flow from cash_flow statement instead of income_statement.

Ticker Extraction Decoupled from SEC Validation

Pure regex extraction, MCP-based validation, first-match heuristic, validation fallback to resolution, ticker format gate.

Financial Filings Tool

get_financial_filings() fetches 10-K and 10-Q separately to avoid 8-K domination.

News System: Concurrent RSS + Yahoo Fallback

All three RSS feeds fetched simultaneously via asyncio.gather(). Yahoo Finance news API fallback when RSS fails. Structured diagnostics in response.

DCF Skipped from High Volatility Routing

dcf_error set in compute_metrics_node before routing. Surfaced in graph.run() output and reasoning text.

DCF Null from Negative Free Cash Flow

Iterates through periods and returns first positive FCF. Comprehensive failure logging for all DCF edge cases.

Ticker False Positives from Financial Acronyms

_FINANCIAL_STOP_WORDS blocklist, clean_query_for_resolution(), failed ticker exclusion from resolution query.

Portfolio Holdings Extraction

Four regex patterns in extract_holdings(). Holdings passed through the chain. Orchestrator LLM instructed to include holdings. Helpful notes instead of empty {}.

Langfuse Span Noise Filtering

Uses is_default_export_span helper. Filters A2A internal spans and HTTPX transport spans. Exports only high-level workflow and LLM spans.

Langfuse Distributed Tracing

Text-based trace context injection via A2A payload JSON prefix. Sub-agents use extract_trace_ids() and start_observation(trace_context=...). LangGraph uses CallbackHandler(trace_context=...).

Date Hallucination

Added Today's date: {date.today().isoformat()} to every LLM prompt.

Persistent Memory Layer

DatabaseSessionService for persistent sessions. SQLiteMemoryService for cross-session search. BM25 + embeddings hybrid search. Dual persistence path (after_agent_callback + _persist_to_memory).
