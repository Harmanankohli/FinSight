AG-UI Bridge + Next.js Frontend (v2 — 2025-05-30)

Updated plan incorporating all backend changes shipped since v1 (Phases 1–4 improvements, memory layer, guardrails, semantic cache, performance tracker, runtime eval) and learnings from the prior feature/web-ui prototype that validated A2A streaming.

Decisions locked in:
  • Bridge mode: Augment — add /a2a-agui endpoint that drives the orchestrator through its A2A JSON-RPC interface. The existing /agentic_chat (Runner-backed, used by RAGAS evaluation) is untouched.
  • Frontend stack: Next.js 16 + CopilotKit (@copilotkit/react-core, @copilotkit/react-ui, @copilotkit/runtime) talking AG-UI to the Python bridge.
  • Feature floor: every capability currently exposed by adk web (sessions, memory, event trace, tool inspection, multi-turn replay) must be available in the new UI before it can replace it.
  • Multi-page layout: two primary views (Research, Operator) adapted to CopilotKit’s sidebar/chat model.
What changed since v1:
  • FinSightAgentExecutor now has inline guardrails: off-topic filter, ticker validation, today’s brief cache, semantic cache, output length/signal checks, memory context injection.
  • Memory layer is complete: TickerMemory, PortfolioStore, PerformanceTracker, SQLiteMemoryService (hybrid BM25+embedding search).
  • SQLiteTaskStore persists A2A tasks across restarts.
  • Per-agent A2A timeouts (A2A_TIMEOUT_RAG, _QUANT, _MARKET_CONTEXT).
  • Agent progress events: executor emits TASK_STATE_WORKING per sub-agent call.
  • Runtime RAGAS eval fires on every response (when EVAL_ENABLED=true).
  • Prior prototype on feature/web-ui validated A2A streaming end-to-end (frontend code was lost when branch was deleted; backend stash survives).

Part A — A2A → AG-UI bridge

1. Current state (updated)

The orchestrator (agent_1_adk/main.py) runs on port 8001 with three route groups:

  • /a2a — A2A JSON-RPC, backed by FinSightAgentExecutor.
  • /.well-known/agent-card — A2A agent-card discovery.
  • /agentic_chat — AG-UI SSE endpoint, Runner-backed, _EVAL_USER_ID = "eval_user".
  • /health — simple JSON health check.

1.1 — FinSightAgentExecutor capabilities (new since v1)

The A2A executor (agent_executor.py) now owns significant business logic that the AG-UI bridge gets for free by routing through /a2a:

3. Event translation table

The bridge consumes A2A events from FinSightAgentExecutor and emits AG-UI events. Updated to reflect actual executor behavior:

A2A event from executorAG-UI event(s) emittedNotes
(connection open)RUN_STARTEDEmit once per run_id.
TaskStatusUpdateEvent (WORKING, msg=“Processing your request…”)STEP_STARTED (name=“orchestrator”)Initial step before any agent calls.
TaskStatusUpdateEvent (WORKING, msg=“Consulting {agent_name}…”)STATE_DELTA (key=active_agent, value=agent_name)Per-agent progress. Source: _emit_agent_progress().
TaskArtifactUpdateEvent (artifact named {agent}-result)TOOL_CALL_START + TOOL_CALL_ARGS + TOOL_CALL_END + TOOL_CALL_RESULTOne complete tool-call cycle per sub-agent response. Artifact name identifies the agent.
TaskStatusUpdateEvent (COMPLETED, msg=final synthesis)TEXT_MESSAGE_START → TEXT_MESSAGE_CONTENT → TEXT_MESSAGE_ENDFinal synthesis text. If >500 chars, chunk into multiple CONTENT deltas.
TaskStatusUpdateEvent (COMPLETED, msg=cached brief)TEXT_MESSAGE_* (same as above)Fast path: today’s cache hit or semantic cache hit. No tool calls emitted.
TaskStatusUpdateEvent (FAILED)RUN_ERRORFrom output guardrails (too short / off-topic / invalid ticker).
TaskStatusUpdateEvent (COMPLETED) + brief JSON in artifactSTATE_SNAPSHOT (key=brief) + CUSTOM eventStructured InvestmentBrief JSON for generative UI rendering.

4. New module: agent_1_adk/agui_bridge.py

Sits next to agui_endpoint.py. Does not replace it.

def make_agui_bridge_endpoint(
    a2a_client_factory: Callable[[], A2AClient],
    *,
    session_service: DatabaseSessionService,
    ticker_memory: TickerMemory,
) -> Callable[[Request], Awaitable[Response]]:
    """Return a Starlette POST handler for /a2a-agui."""

Internal pieces:

  • _A2AToAGUI — stateful translator; per-run state: pending_calls: dict[str, str], msg_id, text_started, active_agents: set[str].
  • _emit(event_obj) -> str — SSE framer. Extract into shared/agui_sse.py so both endpoints share it.
  • _extract_user_text(payload: RunAgentInput) -> str — from agui_endpoint.
  • _resolve_session(thread_id, run_id, payload) -> SessionHandle — see §5.
  • _parse_agent_from_artifact(artifact_name: str) -> str — extracts agent name from artifact names like financial-rag-agent-result.
Design simplification (v2): Because FinSightAgentExecutor now handles all guardrails, caching, and memory persistence inline, the bridge is purely a translator — it maps A2A events to AG-UI events and manages session identity. No business logic in the bridge.

Same principle as v1, now with additional stores:

6. Trace propagation + Langfuse

The executor already starts a Langfuse span (finsight-query) per A2A task and injects W3C traceparent into sub-agent calls via shared/trace_context.py. The bridge adds:

  1. Start a parent OTel span agui.run on each incoming POST.
  2. Stamp thread_id, run_id, user_id as span attributes.
  3. The executor’s child span inherits from the bridge’s span.
  4. After RUN_FINISHED, emit a CUSTOM event: {type: "langfuse_trace", url: "..."} so the UI shows a “View trace” chip.

8. Step-by-step implementation

8.1 — Extract shared SSE helper tier 0

~20 min

  1. Create shared/agui_sse.py with sse(event) -> str.
  2. Replace _sse in agui_endpoint.py with the import.
  3. Verify: python -m pytest tests/evaluation/ -k agui -q

8.2 — Scaffold bridge module tier 1

~1–2 hrs

  1. New file agent_1_adk/agui_bridge.py per §4.
  2. Internal A2A client: reuse a2a.client.ClientFactory pointed at http://{HOST}:{PORT}/a2a. Even though same-process, going over HTTP guarantees AG-UI and external A2A paths are identical.
  3. Implement the translator per §3. Use a dataclass RunCtx for per-run state (msg_id, pending_calls, text_started, active_agents).
  4. New (v2): Parse artifact names to extract agent identity (e.g. financial-rag-agent-result → “Financial RAG Agent”). The executor normalizes agent names in artifact names.

8.3 — Wire route in main.py tier 0

~15 min

from .agui_bridge import make_agui_bridge_endpoint

routes.append(Route(
    "/a2a-agui",
    make_agui_bridge_endpoint(
        a2a_client_factory=lambda: build_local_a2a_client(HOST, PORT),
        session_service=session_service,
        ticker_memory=TickerMemory(),
    ),
    methods=["POST"],
))

8.4 — REST API routes tier 1

~2 hrs

  1. Add all routes from §7 as Starlette route handlers in main.py (or factor into agent_1_adk/api_routes.py if >6 routes).
  2. Each route reads user_id from X-FinSight-User-Id header.
  3. All use existing memory layer classes — no new DB queries.
  4. Add CORS middleware for localhost:3000 (dev) and configurable origins.

8.5 — User identity tier 1

~1 hr

  1. Read X-FinSight-User-Id header from request (set by Next.js).
  2. If absent, check CopilotKit’s properties.user_id in payload.
  3. If still absent, mint anon-{uuid4} and return in response headers; Next.js stores in cookie.
  4. Never default to eval_user — reserved for RAGAS.
  5. Never default to a2a_user — that’s the A2A-client fallback.

8.6 — Cancellation tier 2

~½ day

AG-UI clients close the SSE connection on stop. The bridge propagates as A2A cancelTask. The executor already has cancel() that calls self._task.cancel(). Wire via Request.is_disconnected() polling in the streaming generator.

9. Backend test plan

  • Unit — tests/agui_bridge/test_translator.py: feed recorded A2A event sequences from executor; assert AG-UI stream matches golden file.
  • Integration — tests/agui_bridge/test_e2e.py: spin up orchestrator, POST RunAgentInput, collect SSE stream, assert RUN_FINISHED and at least one TOOL_CALL_START per sub-agent.
  • Fast-path — test that a cached-brief query returns TEXT_MESSAGE_* without any TOOL_CALL_* events.
  • Guardrail — test that off-topic/invalid-ticker queries return RUN_ERROR or TEXT_MESSAGE_* with rejection text.
  • REST API — tests/api/test_rest_routes.py: hit each /api/* route with test data in the SQLite DB; assert JSON shape.

13. “Killer” features — generative UI

13.1 — Live sub-agent “thinking” tiles

Three tiles (RAG / Quant / Market Context) driven by STATE_DELTA on key active_agent. Each tile shows animated status. On completion, flips to one-sentence summary + expandable artifact.

┌─────────────────────────────┐ ┌─────────────────────────────┐ ┌─────────────────────────────┐ │ ● RAG (LlamaIndex) │ │ ● Quant (LangGraph) │ │ ● Market Context (CrewAI) │ │ indexing 12 SEC filings… │ │ running DCF + stress… │ │ macro regime + peers… │ │ ▓▓▓▓▓▓▓░░ 72% │ │ ▓▓▓▓▓░░░░░ 48% │ │ ▓▓▓▓▓▓▓▓▓▓ 100% ✓ │ └─────────────────────────────┘ └─────────────────────────────┘ └─────────────────────────────┘
v2 note: The prior prototype validated this pattern with an OrchStrip component showing 4 orchestration steps. The CopilotKit version uses useCoAgentStateRender to render these tiles inline in the chat.

13.2 — Investment Brief card (structured)

When the final investment_brief artifact arrives: BUY/HOLD/SELL chip, confidence meter, key catalysts & risks columns, citations with clickable filing links, and a DCF/Sharpe/VaR mini-panel.

v2 note: The prior prototype’s SynthesisCard component validated the basic layout. CopilotKit version extends it with useCopilotAction for interactive drill-down into each section.

13.3 — Inline price chart

Ticker symbols in assistant text autolink to a TradingView Lightweight Chart popover (6-month daily candles). Data via a Next.js edge function that proxies get_prices from the MCP server.

13.4 — Memory timeline sidebar

Per-ticker timeline of past briefs from TickerMemory.get_history(): date, recommendation, confidence, and realized return (from PerformanceTracker). Click to load historical brief.

13.5 — “What changed?” diffing

When a ticker is queried again, call TickerMemory.has_changed(ticker) to detect recommendation changes. Show a diff card: new vs. old recommendation, confidence delta, new catalysts/risks. Uses GET /api/memory/ticker/{sym}/changed.

13.6 — Trace deep-link

“Open in Langfuse” chip in the trace drawer footer, linking to the Langfuse trace URL from the bridge’s CUSTOM event (§6).

14. Human-in-the-loop checkpoints

CopilotKit’s renderAndWaitForResponse on useCopilotAction gates three orchestrator behaviors:

  1. Before large external fetches — if orchestrator requests >10 SEC filings or full-text search, ask user to approve (cost & latency).
  2. Before writing to memory — show the brief snapshot about to be persisted; user can edit notes before save.
